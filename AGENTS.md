# Profile README

Read [the design guide](docs/design-guide.md) before changing this profile.
The approved reference is [the coastal concept](docs/reference/coastal-readme-concept.png).

- Keep the coastal research station, small white astronaut, and teal / cream / coral palette.
- Keep two featured projects. When a new project is requested, consider replacing a
  feature rather than appending another card. Put the wider catalogue on the website.
- Keep project names, descriptions, links, contribution status, and navigation as real
  text in `README.md`. Updating copy does not require regenerating an illustration.
- Preserve clear prose. Follow `polish-open-source-prose` when available; check facts
  and links against the relevant repository before changing claims.
- Only describe a contribution as merged after checking its upstream pull request.
- Use GitHub-supported Markdown / HTML. The profile cannot run custom CSS or JavaScript.
  Check GitHub's rendered output, narrow screens, and light and dark themes.
- Keep images in `art/`, the reference in `docs/reference/`, and generation prompts in
  `docs/asset-prompts.md`. Record asset replacements in the design guide.
- The older typographic SVGs and `tools/build_art.py` belong to the previous design.
  Do not run that generator to rebuild the coastal illustrations.
